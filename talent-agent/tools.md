# Talent Agent Tools

## Stack Preferencial
- **Markdown:** Formato base para currículos devido à sua portabilidade e clareza para sistemas de parse.
- **LinkedIn:** Referência para social proof e networking.
- **Job Description Analyzers:** Ferramentas (ou prompts) para extração de entidades e keywords.
- **Grammarly / LanguageTool:** Garantia de correção gramatical impecável.

## Workflow de Ferramentas
1. **Análise:** Input da vaga -> Extração de keywords.
2. **Edição:** Markdown -> Aplicação de keywords e STAR Method.
3. **Exportação:** Markdown -> PDF (via Obsidian, Pandoc ou similar).
4. **Sincronização:** Atualização do LinkedIn com base no novo currículo.

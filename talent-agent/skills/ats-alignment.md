# Skill: ATS Alignment

## Quando Usar
Crucial para candidaturas em portais de grandes empresas (Gupy, Workday, Taleo).

## Padrões e Decisões
- **Keyword Density:** Incluir as tecnologias e competências citadas na vaga de forma natural.
- **Nomenclatura de Seções:** Usar nomes padrão como "Experiência Profissional", "Formação Acadêmica" e "Habilidades".
- **Simplicidade Técnica:** Evitar cabeçalhos/rodapés complexos, tabelas e imagens.
- **Siglas e Extenso:** Usar tanto a sigla quanto o nome por extenso (ex: "Application Programming Interface (API)").

## Anti-padrões
- Tentar enganar o ATS com texto branco escondido (pode causar desclassificação automática).
- Usar formatos de arquivo não padrão (preferir PDF gerado a partir de texto limpo).

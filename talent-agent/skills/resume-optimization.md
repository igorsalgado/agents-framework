# Skill: Resume Optimization

## Quando Usar
Sempre que um currículo precisar de uma atualização estrutural ou de conteúdo para aumentar as chances de ser lido por um humano.

## Padrões e Decisões
- **Ordem Cronológica Inversa:** Priorizar a experiência mais recente.
- **Resumo Executivo:** 3 a 4 linhas focadas em anos de experiência + especialidade + maior conquista.
- **Hierarquia Visual:** Usar `#` para nome, `##` para seções e `###` para cargos.
- **Verbos de Ação:** Iniciar cada bullet point com verbos fortes (Desenvolvi, Liderei, Otimizei, Implementei).

## Anti-padrões
- Listar tarefas em vez de conquistas.
- Incluir foto, idade, estado civil ou RG (exceto se exigido por lei local).
- Usar colunas laterais que quebram a leitura linear.

## Critérios Práticos
- O currículo deve ter no máximo 2 páginas.
- Fontes padrão (Arial, Calibri, Roboto) para a exportação final.
